## 3. 缺陷详情

### #148-D1 [P2] uninstallLinux 非幂等

**位置**：`src/watchdog.ts` `uninstallLinux()`（约 line 152-165）

**现象**：第二次 `chorusgate watchdog uninstall --agent <id>` 报错并 exit 1：
```
✘ systemctl disable failed: Failed to disable unit: Unit chorusgate-watchdog-<id>.timer does not exist
```

**根因**：`uninstallLinux` 先执行 `rmSync(join(unitDir, timer/service))` 删除 unit 文件，然后调用 `systemctl --user disable --now`。此时 unit 文件已不存在，systemctl 报 "Unit does not exist" 并返回非零退出码。`rmSync` 与 `systemctl disable` 顺序颠倒——应先 disable 再 rm，或 disable 失败时先检查 "not loaded/not found" 正则并 return 0（与 Windows 版 `uninstallWindows` 对齐）。

**对比**：`uninstallWindows`（line 78-90）正确处理了此情况——schtasks 返回非零时检查 `/does not exist|not find/找不到/i` 正则，匹配则 return 0（"nothing to uninstall"）。Linux 版的正则检查（line 160-162）存在但因 `rmSync` 先执行，unit 已被删导致 systemctl 输出 "does not exist" 但该字符串未被正则匹配（实际输出是 `Failed to disable unit: Unit ... does not exist`，正则 `/Unit .* not loaded|not found/i` 不匹配 "does not exist"）。

**影响**：违反 AC-9 "install/uninstall 必须幂等"。非 P0（不影响正常运行时守护），但验收标准明确要求幂等。

**修复建议**：
```typescript
function uninstallLinux(agentId: string): number {
  const name = watchdogTaskName(agentId);
  const unitDir = join(homedir(), ".config", "systemd", "user");
  // 1. 先 disable（可能 unit 已不存在，允许失败）
  const r = spawnSync("systemctl", ["--user", "disable", "--now", `${name}.timer`], { encoding: "utf8" });
  const out = (r.stderr || "") + (r.stdout || "");
  // 2. 无论 disable 结果都删除 unit 文件
  rmSync(join(unitDir, `${name}.service`), { force: true });
  rmSync(join(unitDir, `${name}.timer`), { force: true });
  // 3. disable 失败但属"不存在"→ 幂等成功
  if (r.status !== 0 && /Unit .* does not exist|not loaded|not found/i.test(out)) {
    console.error(`✔ watchdog '${name}' not found — nothing to uninstall`);
    return 0;
  }
  if (r.status !== 0) {
    console.error(`✘ systemctl disable failed: ${out.trim()}`);
    return 1;
  }
  console.error(`✔ watchdog uninstalled: '${name}.timer'`);
  return 0;
}
```

关键修改：
1. `rmSync` 移到 `systemctl disable` 之后（先 disable 再删文件）
2. 正则增加 `does not exist`（对齐实际 systemd 输出）
